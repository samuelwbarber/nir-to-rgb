# Deployment evidence

`pi/` contains the original Raspberry Pi 5 CPU and Hailo-8L benchmark outputs,
sustained-run and thermal measurements, and the LiteRT benchmark script used
alongside the [final report](../report/main.pdf).

These are recorded measurements from the research hardware. Original paths,
timestamps and device details are preserved as provenance. Model binaries are
not bundled. Training/evaluation measurements are under
[`training/experiments/`](../training/experiments/).
