The loss: supervise in feature space

Both images run through the same frozen networks; training pushes their features together (never the raw pixels).

We never compare pixels. Both the translation and the real RGB go through the same frozen networks (DINOv2, CLIP, ResNet-50), and training pushes their features together. This replaces the single VGG perceptual term, on an unmodified backbone, kept alongside an L1 colour anchor, MS-SSIM and a light PatchGAN.

❄ = frozen: the extractor weights never change; gradients flow through them to the translator.
